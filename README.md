## Overview

Ghost Intel is a full-stack Web3 application that combines AI-driven lead enrichment with on-chain credit management. Sales professionals paste a LinkedIn URL, and the platform instantly returns verified contact details along with a personalised icebreaker message generated by Google Gemini — all powered by a transparent credit economy running on Base Sepolia.

### How It Works

```
LinkedIn URL  →  FullEnrich API  →  Verified Contact Data
                                          ↓
                                   Google Gemini AI  →  Personalised Icebreaker
                                          ↓
                           Base Sepolia Smart Contracts  →  Credit Deduction + Reputation
```

## Features

| Feature | Description |
|:--------|:------------|
| 🔍 **Lead Enrichment** | Extract verified emails, phone numbers, and professional data from LinkedIn profiles via the FullEnrich API. |
| 🤖 **AI Icebreakers** | Google Gemini analyses enriched profiles and generates personalised outreach openers. |
| 💳 **On-Chain Credits** | Purchase credits with ETH or USDC through the `GhostCredits` smart contract. Each search costs 1 credit. |
| 🏆 **Reputation System** | Earn reputation points (10 per search) and level up across 4 tiers as you use the platform. |
| 🎖️ **NFT Badges** | Automatically mint soulbound `GhostNFT` badges at milestones (10, 50, 100, 500, 1000 searches) — Bronze through Diamond. |
| 🤝 **Referral Program** | Create a unique referral code and earn bonus credits (default 10%) whenever your referrals purchase credits. |
| 🔒 **Wallet Auth** | Connect via MetaMask or any injected wallet. No email/password required. |

## Getting Started

### Prerequisites

- **Node.js** v18+
- **npm** or **pnpm**
- **Git**
- **[Foundry](https://getfoundry.sh/)** (for smart contract development)
- A Web3 wallet (e.g. MetaMask) configured for **Base Sepolia**

### 1. Clone & Install

```bash
git clone https://github.com/Emafido/ghost.git
cd ghost
npm install
```

### 2. Environment Variables

Create a `.env.local` in the project root:

```env
NEXT_PUBLIC_API_BASE=https://ghost-intel-backend.onrender.com/api
```

For backend environment setup, see [BACKEND_README.md](BACKEND_README.md).

### 3. Run the Dev Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Smart Contract Setup (Optional)

If you need to compile, test, or redeploy the contracts:

```bash
cd contracts
forge install
forge build
forge test
```

#### Deploy to Base Sepolia

```bash
forge script script/DeployGhost.s.sol:DeployScript \
  --rpc-url $BASE_SEPOLIA_RPC \
  --broadcast \
  --verify
```

After deployment, update the addresses in [`app/constants.ts`](app/constants.ts).

## Smart Contracts

Both contracts are deployed on **Base Sepolia**:

| Contract | Address | Standard |
|:---------|:--------|:---------|
| **GhostCredits** | `0x592818F05E5EbA208D1A58E7d382D74171ee19a9` | Custom (Ownable, Pausable, ReentrancyGuard) |
| **GhostNFT** | `0x6091f4ff7dc215830d0b7b83d67bbe9096b95601` | ERC-721 (Soulbound) |

### GhostCredits

Manages the platform's credit economy:

- **Purchase credits** with ETH (`purchaseCreditsETH`) or USDC (`purchaseCreditsUSDC`)
- **Record searches** — deducts 1 credit, increments reputation, and checks badge milestones
- **Referral system** — create/use referral codes; referrers earn a configurable bonus on purchases
- **Owner controls** — pause/unpause, adjust rates, withdraw funds, transfer ownership

### GhostNFT

Soulbound (non-transferable) ERC-721 badges awarded at search milestones:

| Milestone | Badge Type | Name |
|:----------|:-----------|:-----|
| 10 searches | 0 | 🥉 Bronze |
| 50 searches | 1 | 🥈 Silver |
| 100 searches | 2 | 🥇 Gold |
| 500 searches | 3 | 💎 Platinum |
| 1000 searches | 4 | 💠 Diamond |

## API Reference

The backend is deployed at `https://ghost-intel-backend.onrender.com/api`.

| Method | Endpoint | Description | Auth |
|:-------|:---------|:------------|:-----|
| `POST` | `/api/search` | Enrich a LinkedIn profile + generate AI opener (costs 1 credit) | — |
| `POST` | `/api/search/regenerate` | Regenerate AI opener for an existing result (costs 1 credit) | — |
| `GET` | `/api/credits/:wallet` | Get credit balance (auto-creates wallet with signup bonus) | — |
| `GET` | `/api/history/:wallet` | Get search history for a wallet | — |
| `POST` | `/api/buy-credits` | Add credits after payment confirmation | — |
| `POST` | `/api/deduct` | Manually deduct credits | Admin |
| `POST` | `/api/record` | Manually push a history entry | Admin |
| `POST` | `/api/admin/*` | Contract admin operations (pause, rates, withdraw, etc.) | Admin |

> For full request/response examples and admin endpoint details, see [BACKEND_README.md](BACKEND_README.md).

## Usage

1. **Connect your wallet** — Click "Connect Wallet" and approve the MetaMask prompt. Switch to Base Sepolia if prompted.
2. **Buy credits** — Click "+ BUY" in the navbar. Send 0.001 ETH per credit via your wallet.
3. **Search a lead** — Paste a LinkedIn URL (e.g. `linkedin.com/in/demoge`) and click "Decrypt".
4. **View results** — See verified contact info (name, email, phone) and the AI-generated icebreaker. Copy either with one click.
5. **Build reputation** — Check your profile modal for reputation score, level, total searches, and referral stats.
6. **Refer friends** — Create a referral code in your profile. Share it to earn 10% bonus credits on their purchases.
